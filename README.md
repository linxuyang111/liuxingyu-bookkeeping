# 🌠 流星雨记账

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 💰 记一笔 | 支出 / 收入一键切换；金额、两级分类、日期、备注，回车或点击快速保存 |
| 📋 账单列表 | 按天分组展示，每天自动统计支出 / 收入小计；收入绿色＋号、支出红色－号 |
| 🧮 月度汇总 | 本月总收入、本月总支出（含日均与笔数）、本月结余（正绿负红） |
| 🔍 筛选搜索 | 按月份、收支类型、分类筛选；备注关键字实时搜索 |
| 📊 统计图表 | 近 12 个月收支对比柱状图 + 结余折线；支出 / 收入构成环形图（月 / 年可切）；分类排行 |
| 🏷️ 分类管理 | 支出与收入两套独立两级分类，支持添加、改名、隐藏、归档（归档不影响已有账单） |
| 📑 数据备份 | 一键导出 Excel 账单（含收支类型列），或用于备份留存 |
| 🔒 隐私安全 | SQLite 本地单文件存储，应用完全不联网，数据只属于你 |

## 🛠 技术栈

| 层 | 技术 |
|---|---|
| 桌面框架 | [Tauri 2](https://tauri.app/)（Rust + WebView2，安装包仅 3MB） |
| 界面 | Vue 3 + TypeScript + Vite + [Element Plus](https://element-plus.org/) |
| 数据 | SQLite（[rusqlite](https://github.com/rusqlite/rusqlite)），金额以「分」为单位整数存储，杜绝浮点误差 |
| 图表 | [Apache ECharts](https://echarts.apache.org/) |
| 导出 | [rust_xlsxwriter](https://github.com/jmcnamara/rust_xlsxwriter) |
| 打包 | NSIS 简体中文安装包（用户级安装，卸载保留数据） |

## 🚀 开发

```bash
# 环境：Node.js + Rust + Tauri CLI（Windows 需 WebView2）

npm install          # 安装界面依赖
npm run tauri dev    # 启动开发模式（窗口运行）
npm run tauri build  # 打包 Windows 安装程序（产物在 src-tauri/target/release/bundle/nsis/）
```

## 📁 项目结构

```
├── src/                  # 前端（Vue 3）
│   ├── components/       # 共享组件（记一笔弹窗等）
│   ├── views/            # 页面（账单 / 统计 / 分类 / 设置）
│   ├── api.ts            # 后端调用封装（Tauri invoke）
│   └── types.ts          # 数据类型定义
├── src-tauri/            # 后端（Rust）
│   └── src/lib.rs        # 数据库、业务逻辑、全部 Tauri 命令
├── CLAUDE.md             # 产品文档（需求、分类设计、里程碑）
└── 使用说明.md            # 用户使用说明
```

## 📝 版本更新记录

### v2.0.0（2026-11-16）—— 收入功能 🎉

- **记收入**：记一笔弹窗顶部新增「支出 / 收入」切换开关，切换后分类自动换成对应体系

- **统计升级**：趋势图升级为收支对比双柱 + 结余折线；构成环形图与排行支持支出 / 收入切换
- **Excel 导出**：新增「收支」列
